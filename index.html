A few things worth knowing

How do I use one?

Open a template, hit “Code”, copy the whole file. It's plain HTML/CSS/JS with one Google Fonts link — drop it straight into a project or wire it to your own auth logic.

Can I change the colors?

Every template is built on CSS custom properties declared in a :root block at the top of the file — the exact names vary by template (some use --gold, others --wine or --copper) but they're easy to spot and re-theme.

Is this actually free?

Yes — MIT licensed. Use it in personal or commercial projects, no attribution required.

Are these accessible?

Every field has a real <label>, password fields carry a show/hide toggle with an updating aria-label, inputs use the correct autocomplete values so password managers behave, and focus states are visible throughout — but you should still test against your own auth flow and content.

How do I know it's actually accessible?

Open any template and check the badge under the title — it runs six real checks against that template's own markup (labels, autocomplete, aria-label on icon buttons, focus-visible, reduced-motion support, password-toggle aria-pressed) and shows you a live pass/fail count, not just a claim in the copy.

Can this wire itself to a backend?

Not automatically — but open the "Connect" tab in any template's modal and pick Firebase, Supabase, or plain fetch. It generates real auth code using that template's actual field IDs, ready to paste in and point at your own project.
