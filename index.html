A few things worth knowing

How do I use one?

Open a template, hit “Code”, copy the whole file. It's plain HTML/CSS/JS with one Google Fonts link — drop it straight into a project or wire it to your own auth logic.

Can I change the colors?

Every template is built on CSS custom properties (--bg, --accent, --radius…) declared at the top of the file, so re-theming is a handful of value edits.

Is this actually free?

Yes — MIT licensed. Use it in personal or commercial projects, no attribution required.

Are these accessible?

Inputs have labels, focus states are visible, and color contrast was checked per palette — but you should still test against your own auth flow and content.
